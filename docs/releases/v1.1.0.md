# NetWatch-Dashboard v1.1.0 — Network Guardian

This release introduces **Network Guardian** for self-hosted defensive LAN monitoring.

### New
- Persistent SQLite scan history and recent network change events
- Trusted/unreviewed device profiles with friendly names
- Detection of new/disappeared devices and changed TCP ports between scans
- IP change events for devices with a usable MAC address
- Network Guardian tab with device counters and event feed

### Improvements
- Corrected Dockerfile build paths
- Optional HTTP Basic authentication via NETWATCH_USERNAME and NETWATCH_PASSWORD
- Cross-origin write protection and security response headers
- Flask updated to 3.1.3
- Docker health check and GitHub CI tests

### Upgrade
Back up your existing data directory before upgrading. Ensure /app/data is persisted. Run the container on a trusted LAN; use HTTPS if credentials are sent across untrusted networks.

The first scan of a target establishes its baseline. Scan the same target again to compare changes. History is persistent, while the live Dashboard's results may reset after a restart.

This is a periodic scanner, not a real-time intrusion detection system.

See docs/network-guardian.md for setup and limitations.
